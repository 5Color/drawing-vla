# Project LiveSketch: 시계열 궤적 기반 자율 라이브 드로잉 AI 제품 기획서

> **"결과 픽셀만 툭 뱉어내는 디퓨전의 시대를 넘어, 인간의 드로잉 과정을 10~15초 동안 실시간으로 그려내는 자율 라이브 스케치 생성 엔진"**

---

## 1. 프로젝트 비전 및 포지셔닝

### 1.1 시장의 결핍과 기회: 왜 디퓨전의 대안인가?
현재 생성형 AI 시장(Midjourney, Stable Diffusion 등)은 **정적 이미지(2D Raster Pixel)**에 매몰되어 있습니다. 
* **과정의 부재:** 5~10초간 불투명한 로딩 바를 보며 기다려야 하며, 생성 과정 자체에서 느끼는 시각적 재미가 없습니다.
* **통제 불가능성:** 완성 후 "선 하나만 수정"하거나 "외곽선만 따로 추출"하는 것이 불가능합니다.
* **결과물의 픽셀화:** 확대 시 픽셀이 깨져 벡터 그래픽(SVG), 실무 디자인 에셋, 레이저 커팅 등으로 직접 활용하기 어렵습니다.

### 1.2 핵심 정의: Live Generative Trajectory
우리는 픽셀을 채우는 회귀 모델이 아니라, **인간의 손놀림 좌표계($x, y, t, \text{pressure}$)**를 학습하여 실시간으로 선을 긋는 **시계열 궤적 생성 모델**을 구축합니다.
* 사용자가 개입하여 노동할 필요 없이, **팔짱 끼고 10~15초 동안 AI가 사람처럼 사각사각 그려나가는 과정을 감상하는 엔터테인먼트 경험**을 제공합니다.
* 손재주가 없는 일반인도 커미션이나 복잡한 툴 없이 아이디어를 순수 벡터 선화와 일러스트로 구현할 수 있도록 돕습니다.

## 2. 제품 경험(UX) 및 인터랙션 설계

### 2.1 3초 'Pick & Play' 인터페이스
타이핑을 고민할 필요 없이 톡톡 선택하고 바로 감상할 수 있는 무마찰(Zero-Friction) UI를 채택합니다.

```
┌────────────────────────────────────────────────────────┐
│ [카테고리]  [전체]  [동물]  [식물/과일]  [사물]  [캐릭터]      │
│ [스타일태그] #미니멀  #귀여운  #러프스케치  #디테일한         │
│ [소품태그]   #선글라스  #모자  #헤드폰  #커피잔             │
├────────────────────────────────────────────────────────┤
│ [직접 입력] "원하는 조합을 입력하세요..."          [스케치 시작] │
└────────────────────────────────────────────────────────┘
```

* **1단계 (대분류 칩):** 가로 스크롤 형태의 직관적인 카테고리 칩 선택.
* **2단계 (키워드 태그):** 스타일, 분위기, 소품 등을 멀티 선택 가능한 토글 버튼.
* **3단계 (자유 인풋창):** 프리셋 외의 상상력을 발휘하고 싶은 유저를 위한 얇고 깔끔한 인풋창.

### 2.2 10~15초 라이브 스케치 연출 (The Live Canvas)
* **인간적 호흡(Human Dynamics):** 기계적인 일괄 출력이 아닌, 곡선 구간 감속, 획 간의 자연스러운 펜 뗌, 획 시작/끝의 가속도를 완벽히 재현.
* **스케치 ASMR 사운드:** 종이 위를 연필이나 딥펜이 사각거리며 긁는 가벼운 Web Audio 효과음 실시간 재생 (ON/OFF 토글).
* **완전 자율 감상:** 사용자에게 불필요한 중간 개입(협업)을 강제하지 않고, 스피드 드로잉 쇼를 보듯 쾌감에만 집중하도록 설계.

## 3. 바이럴(Virality) 및 산업적 상업화 전략

### 3.1 바이럴 루프: 1-Click 숏폼 내보내기
* **15초 릴스/쇼츠/틱톡 자동 생성:**
  * 드로잉이 완료되는 순간 `[쇼츠용 영상 저장]` 버튼 하나로 10~15초짜리 드로잉 타임랩스 세로형 비디오(MP4/GIF)를 즉각 추출.
  * "AI한테 고양이 그려달라 했는데 손맛 실화냐" 형태의 숏폼 콘텐츠가 유저들에 의해 자발적으로 SNS에 확산.
* **인간 vs AI 대결 플랫폼 연계:**
  * 기존 `Hand vs AI` 플랫폼을 통해 "내가 그린 사과 vs AI가 그린 사과" 스코어 카드 및 비교 릴스 제공.

### 3.2 상업적 실용성: 순수 벡터(SVG) 에셋
* **무손실 무한 해상도:** 확대해도 절대 깨지지 않는 순수 SVG 벡터 코드로 출력.
* **적용처:**
  * 굿노트/노션 다이어리 꾸미기(다꾸) 스티커팩.
  * 레이저 각인기, 플로터, CNC 커팅기용 도안.
  * 디자이너, 웹툰 작가들의 기초 선화 러프 에셋 (Figma, Illustrator 호환).

## 4. 확장성 로드맵: 2단계 채색(Coloring) 아키텍처

선화 엔진과 채색 엔진을 한 모델로 묶지 않고, **2-Stage(선화 $\rightarrow$ 채색)**로 분리하여 선화 모델의 경량성과 정밀도를 완벽히 보존합니다.

```
[1단계: 선화 궤적 엔진 (10~12초)] ──▶ [2단계: 스마트 채색 모듈 (2~3초)]
  - 펜 좌표/필압 스트리밍           - 폐곡선/영역 세그멘테이션 인식
  - 순수 벡터 외곽선 구축          - 스마트 플러드 필 (셀 애니메이션 채색)
                                   - 마커 텍스처 / 수채화 브러시 레이어
```

### 4.1 시스템 확장 설계 (사전 반영 항목)
1. **듀얼 캔버스 렌더링 구조:**
   * 프론트엔드에서 `Line Layer Canvas`와 `Color Layer Canvas`를 레이어로 분리하여 렌더링.
2. **데이터 스키마 확장 필드:**
   * 궤적 데이터에 `layer: 'stroke' | 'fill'`, `fill_color?: string` 필드를 옵셔널로 선제 정의하여 추후 마이그레이션 방지.
3. **채색 연출 시나리오:**
   * 전체 15초 중 12초간 정교하게 선을 딴 뒤, 마지막 3초 동안 마법처럼 팔레트 컬러가 '탁, 탁' 채워지며 완성되는 극적인 시각적 도파민 연출.

## 5. 기술 파이프라인 및 아키텍처

```
┌───────────────────────────────────────────────────────────────┐
│                     High-Level Planner                        │
│   (프롬프트/키워드 입력 ──▶ 1초 내 전체 도안 뼈대 & 핵심 앵커 생성)      │
└───────────────────────────────┬───────────────────────────────┘
                                │ Anchor Points & Stroke Sequence
                                ▼
┌───────────────────────────────────────────────────────────────┐
│              Low-Level Motor Policy (Trajectory)              │
│    (인간 시연 궤적 기반 Action Chunking ──▶ 30~50Hz 좌표 스트리밍)    │
└───────────────────────────────┬───────────────────────────────┘
                                │ WebSocket / SSE Coordinates
                                ▼
┌───────────────────────────────────────────────────────────────┐
│                      Front-end Live Canvas                    │
│      - 캔버스 실시간 렌더링 + 연필 ASMR 사운드 재생                    │
│      - 스마트 채색 레이어 오버레이 + 1-Click SVG/MP4 내보내기           │
└───────────────────────────────────────────────────────────────┘
```

### 5.1 현행 데이터 수집 플랫폼(`Hand vs AI`)의 역할
* **양질의 인간 시연(Demonstration) 수집 엔진:**
  * 상업적 모델 학습의 최대 병목인 **시간-좌표-필압 시계열 데이터**를 웹 게임을 통해 대량 수집.
* **원칙:**
  * 프론트엔드에서 복잡한 가이드로 유저를 억압하지 않고(연한 시작점 하나만 부여), 자연스러운 손놀림 수집.
  * `dataset.py`에서 온더플라이로 획 방향(`[::-1]`)과 순서를 정규화하여 모델 학습 안정성 확보.
  * 푸터에 간결한 안내 문구 및 [내 기록 삭제] 셀프 버튼을 배치하여 법적·윤리적 클린 데이터 파이프라인 유지.
